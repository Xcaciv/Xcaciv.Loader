# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | Supported |
| 1.x     | Not supported (end of life 2026-06-01; see [MIGRATION-v1-to-v2.md](docs/MIGRATION-v1-to-v2.md)) |

Only the latest 2.x release is actively maintained. There is no formal support
SLA — this is a single-maintainer open source project — but security reports
against a supported version are taken seriously and prioritized over other
work.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately using GitHub's built-in
reporting tool rather than a public issue:

**[Report a vulnerability](https://github.com/Xcaciv/Xcaciv.Loader/security/advisories/new)**
(Security tab → "Report a vulnerability")

This keeps the report confidential until a fix is available. Include:
- The affected version
- A description of the issue and its potential impact
- Steps to reproduce, or a minimal repro if possible

If you're unsure whether something qualifies, or the tool above isn't
available to you, open a normal [GitHub issue](https://github.com/Xcaciv/Xcaciv.Loader/issues)
without exploit details and ask for a private channel.

There is no bug bounty program.
